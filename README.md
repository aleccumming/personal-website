# alecgcumming.com

Personal portfolio site. Vite + React + TypeScript + Tailwind CSS v4.

## Development

```shell
npm install
npm run dev
```

## Build & deploy

```shell
npm run build     # type-check + production build to dist/
npm run deploy     # build and publish dist/ to the gh-pages branch
```

Content (bio, work history, projects, skills) lives in [`src/data/content.ts`](src/data/content.ts).
